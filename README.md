CharForge 0.1.2-beta — закрытое тестирование
===========================================

Спасибо, что согласились попробовать CharForge! Это ранняя beta, а не
публичный релиз. Пожалуйста, сохраняйте резервные копии данных.

ЧТО ЭТО
-------
Офлайн-менеджер персонажей D&D 2024 для Windows и Android.
Шесть разделов: Бой, Персонаж, Инвентарь, Магия, Биография, Дневник.
Поддерживаются импорт/экспорт Long Story Short JSON v2 и локальные резервные
копии CharForge.

УСТАНОВКА — WINDOWS
--------------------
1. Распакуйте архив CharForge-0.1.2-beta-windows-x64.zip в отдельную папку.
2. Запустите charforge.exe.
3. Windows может показать SmartScreen, потому что EXE не подписан
   коммерческим сертификатом. Проверьте, что архив получен от меня, и выберите
   «Подробнее» → «Выполнить в любом случае».
4. Не запускайте EXE из самого ZIP-архива: сначала распакуйте.
5. Требуется 64-битная Windows 10/11.

УСТАНОВКА — ANDROID
-------------------
1. Передайте на телефон файл CharForge-0.1.2-beta-android.apk.
2. Разрешите установку из этого источника в настройках Android.
3. Откройте APK и установите.
4. APK подписан тестовым ключом, а не ключом Google Play. Для тестирования это
   нормально; при обновлении не удаляйте приложение без резервной копии.
5. Требуется Android 7.0+ (minSdk 24). Проверено на эмуляторе API 37.

ПЕРВЫЙ ЗАПУСК
-------------
1. Выберите D&D 5.5e / 2024.
2. Откройте библиотеку.
3. В библиотеке уже есть демонстрационный Каэль; можно импортировать свой LSS
   JSON.
4. Перед экспериментами сделайте резервную копию через меню данных библиотеки.

ЧТО ПРОВЕРИТЬ
-------------
- Создание персонажа: класс → вид → предыстория → характеристики → навыки.
- Импорт LSS, сохранение биографии/портрета/оружия и повторный экспорт.
- Изменение ОЗ, отдых, ресурсы, броски и журнал.
- Закреплённые боевые действия: оружие/заклинание/ресурс, порядок и удаление.
- Вкладка «Персонаж»: клики по проверкам/спасброскам/навыкам, пассивные
  чувства, переключение владения/экспертизы точкой.
- Перезапуск приложения и проверку, что персонажи и закрепления на месте.
- Резервную копию CharForge: создать, изменить данные, восстановить.

ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ
---------------------
- Поддерживается только D&D 2024; 2014 явно помечена как неготовая.
- Нет облака, аккаунта и синхронизации между устройствами.
- Нет автоматического импорта в сервис Long Story Short; проверяется файловый
  экспорт/импорт.
- Часть классовых особенностей, заклинаний и эффектов ведётся вручную.
- Android-версия проверена на эмуляторе API 37; физический телефон ещё нет.
- APK подписан тестовым ключом; Windows EXE не подписан.
- Не используйте beta как единственное хранилище важной кампании.

ДАННЫЕ И ВОССТАНОВЛЕНИЕ
-----------------------
- Данные локальные; удаление приложения/очистка данных может их удалить.
- Резервная копия: библиотека → меню данных → «Резервная копия библиотеки».
- Восстановление: библиотека → меню данных → «Восстановить из копии».
- Если приложение сообщает об ошибке записи, сделайте backup и напишите мне.

КАК ДАВАТЬ ОБРАТНУЮ СВЯЗЬ
-------------------------
Пришлите:
1. Платформу и версию ОС.
2. Что делали по шагам.
3. Что ожидали и что произошло.
4. Скриншот.
5. Для проблем с данными — резервную копию CharForge и, если возможно,
   исходный LSS JSON.

Пожалуйста, не публикуйте beta-сборки и не передавайте их дальше без

ЧТО НОВОГО В 0.1.2-beta
------------------------
- Заклинания: полные карточки, удаление/снятие подготовки, каст с ячейками,
  концентрацией и бросками.

- Повышение уровня: хиты, ASI, XP/Milestone, выбор класса мультикласса,
  история и отмена.
